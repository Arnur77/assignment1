# HTML & CSS Basics — Assignment #1

## Description
This repository contains Tasks 1–5 for the HTML & CSS Basics assignment.

## Tasks
- Task 1: Personal profile webpage
- Task 2: Div + float layout without Flexbox or Grid
- Task 3: Alan Turing tribute page
- Task 4: Student grades table and feedback form
- Task 5: Portfolio website topic, sitemap and wireframe design

## How to run
Open `index.html` in a web browser.

## GitHub Pages
After uploading the files to GitHub:
1. Open the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the website.

## Important
Replace `[YOUR GROUP]` in `index.html` with your actual university group.
