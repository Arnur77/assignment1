## Project Overview

This project contains five tasks created using HTML and CSS.  
The purpose of the assignment is to practice basic web development concepts such as HTML structure, CSS styling, page layouts, tables, forms, navigation, and responsive design.

---

## Tasks

### Task 1 — Personal Profile Webpage

Created a personal profile webpage using HTML and CSS.

The page includes:
- Personal information
- Headings and paragraphs
- Ordered and unordered lists
- Profile image with alternative text
- Links to external websites
- CSS styling
- Profile card
- Hover effects
- Responsive design

---

### Task 2 — Div and Float Layout

Created a webpage layout using `div` elements and CSS positioning.

The layout contains:
- Header
- Navigation bar
- Sidebar
- Main content area
- Footer

The task was completed without using Flexbox or CSS Grid.

---

### Task 3 — Alan Turing Tribute Page

Created a tribute webpage dedicated to **Alan Turing**.

The page contains:
- Information about Alan Turing
- His achievements and contributions
- Image
- Structured sections
- Styled content
- Links to additional information

---

### Task 4 — Grades Table and Feedback Form

Created a styled webpage containing:
- Students' grades table
- Table headers and rows
- Different CSS styles
- Feedback form
- Text input fields
- Select elements
- Radio buttons
- Submit button

The task demonstrates the use of HTML tables and forms together with CSS styling.

---

### Task 5 — Portfolio Website

Designed the structure of a portfolio website.

The project includes:
- Website topic
- Sitemap
- Website structure
- Wireframe ideas
- Five main pages

The planned pages are:

1. Home
2. About
3. Projects
4. Services
5. Contact

The sitemap and wireframe demonstrate how the pages are connected and how the website structure is organized.
